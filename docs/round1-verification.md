## 实际验证

| 验证 | 结果 |
| --- | --- |
| 新接口实现前的 HTTP 检查 | 两个场景因接口不存在返回 404 而失败，验证确实覆盖新增能力 |
| Maven clean verify，H2 临时文件数据库 | 2 个集成场景，0 失败、0 错误、0 跳过 |
| Maven verify，独立真实 MySQL 8.4.10 | 2 个集成场景，0 失败、0 错误、0 跳过 |
| 缺少身份、错误 AppID、缺失来源、重复身份头 | 返回 401 |
| 未开启可信入口但携带伪造身份头 | 返回 503 |
| 6 个并发请求首次登记同一用户 | 返回相同 userId |
| 中文、表情、名片八字段保存 | 正常读回，UTC 时间戳一致 |
| 非法电话、邮箱、类型、null、超长、未知字段、客户端用户标识、损坏 JSON | 返回 400，既有名片保持不变 |
| 不同用户、大小写不同 OpenID | 隔离，不能读取另一用户的名片 |
| 全量替换名片 | 省略字段清为空字符串，与 PUT 契约一致 |
| 关闭应用上下文后重新启动 | 用户标识和名片保持一致 |
| 启动打包 JAR → HTTP 保存 → 关闭 Java 进程 → 重启同一 JAR | 实际 MySQL 中的用户与名片成功恢复 |
| 小程序工作区复核 | 保持原有 project.config.json 修改和 .codex-transaction/，本轮未修改小程序 |

实际构建运行环境为 Windows、JetBrains JDK 25.0.3、Maven 3.9.16；编译目标 Java 21。MySQL 为本轮独立临时实例，仅监听 127.0.0.1:13316，不是云数据库。测试身份由测试代码模拟可信入口注入，用于验证后端逻辑。

可部署产物：target/springboot-wxcloudrun-1.0.jar。H2、测试代码和本地密码均不进入该 JAR。
